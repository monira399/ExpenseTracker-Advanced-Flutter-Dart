# 💰 Expense Tracker

A modern Flutter Expense Tracker application to manage daily income and expenses with a clean and user-friendly interface.

## ✨ Features

- 📊 Dashboard with expense overview
- 💸 Add Income & Expense
- 🏷️ Category Management
- 📅 Transaction History
- 🔍 Search & Filter Transactions
- 📈 Financial Summary
- 🌙 Clean & Modern UI
- 🔥 Firebase Integration (In Progress)

## 🛠️ Built With

- Flutter
- Dart
- Firebase (In Progress)
- Material Design

## 📱 Screens

- Splash Screen
- Home Dashboard
- Add Transaction
- Category Management
- Transaction History
- Profile

## 🚀 Getting Started

```bash
flutter pub get
flutter run
```
